## 4. Подтверждённая архитектура меню и TV

Правильный Laravel-репозиторий — sergeniyrus/daodes-space. Репозиторий DAODES-Blockchain/daodes.space — другой старый PHP-сайт, не текущий Laravel-проект.

Подтверждённые файлы и поведение на main:

- app/Http/Controllers/OrganizationTVController.php
  - show() выводит публичный экран организации.
  - Использует organizations.tv_screens_count и tv_screens_config.
  - Загружает активные разделы организации по tv_screen и активные блюда.
  - Поддерживает ?screen=4.
  - shorthand-параметры ?1, ?2, ?3 ограничены старым циклом; для TV4 использовать ?screen=4.
  - createScreen() увеличивает количество экранов, максимум 20.

- routes/web.php
  - Публичный маршрут GET /organization/{organization}/tv, имя organization.tv.
  - Создание экрана POST /{organization}/tv-screens, имя organizations.tv.screens.store.
  - Настройки PATCH /{organization}/tv-screens/{screen}/settings, имя organizations.tv.screens.settings.
  - Старые /tv1, /tv2, /tv3 и их контроллеры остаются отдельными, менять их нельзя.
- app/Http/Controllers/OrganizationMenuController.php — существующий CRUD разделов и блюд.
- app/Models/MenuSection.php — поля organization_id, name, sort_order, tv_screen, is_active и fulfillment flags.
- app/Models/MenuItem.php — поля menu_section_id, name, weight, unit, price, description, sort_order, is_active, image CID/path и fulfillment flags.
- resources/views/organizations/manage.blade.php — управление количеством TV-экранов, названием, фоном и автопереключением.
- resources/views/organizations/menu/sections/create.blade.php — выбор экрана TV при создании раздела.
- resources/views/organizations/menu/index.blade.php — быстрое изменение назначения раздела на TV.
- resources/views/tv/organization.blade.php — универсальное представление динамических экранов организации.

Существующая реализация уже поддерживает TV4. Отдельный TV4Controller, отдельный статический Blade-шаблон или новый маршрут не нужны. Не создавать параллельную систему TV4.

## 14. Безопасная синхронизация цен TV5–TV6 (2026-11-27)

- `tests/Unit/SyncOrganizationTwoTopTvPricesTest.php`
- `.github/workflows/tv4-menu-checks.yml` — включены PHP lint и PHPUnit для новой команды.

Принцип работы:
- Источник цены — активное блюдо на TV1–TV4 организации №2.
- Цель — соответствующая активная копия на TV5 или TV6.
- Сопоставление выполняется по нормализованному названию.
- Перед обновлением проверяется уникальность исходной позиции и полное совпадение всех остальных полей: вес, единица измерения, описание, image_path, image_cid и fulfillment flags.

- Изменяется исключительно поле `price`; названия, состав, вес, изображения, сортировка и флаги доступности не меняются.
- Dry-run выполняется по умолчанию. Применение возможно только с `--apply`.
- При применении предварительная проверка и обновление выполняются внутри одной DB-транзакции.

```bash
php artisan menu:sync-org2-top-tv-prices
```
