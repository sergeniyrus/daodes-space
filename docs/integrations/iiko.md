# Интеграция DAODES × iikoCloud

## 1. Архитектура

Интеграция реализована отдельным модулем Laravel в app/Services/Iiko.

- DAODES остаётся основной системой онлайн-заказов и хранит собственные заказы.
- iiko остаётся системой ресторана: касса, кухня, склад, финансовый учёт и ресторанные справочники.
- API Key хранится отдельно для каждой организации DAODES и шифруется Laravel encrypted cast.
- appId и clientSecret — общие реквизиты приложения DAODES, хранятся только в окружении.
- Одна iiko-организация может быть привязана только к одной организации DAODES.
- Все очереди и вебхуки проверяют организацию и выбранную терминальную группу.

## 2. Переменные окружения

Добавить на сервере в .env:

    IIKO_BASE_URL=https://api-ru.iiko.services
    IIKO_APP_ID=
    IIKO_CLIENT_SECRET=
    IIKO_TIMEOUT=20
    IIKO_CONNECT_TIMEOUT=5
    IIKO_TOKEN_CACHE_MINUTES=55
    IIKO_WEBHOOK_URL=https://daodes.space/api/integrations/iiko/webhook

Не помещать реальные секреты в GitHub, миграции, логи или Blade.

После изменения .env обновить конфигурационный кэш штатным способом проекта.

## 3. Первичное подключение

1. Получить appId и clientSecret приложения DAODES в кабинете разработчика iiko.
2. Получить отдельный API Key тестового ресторана.
3. В настройках организации DAODES открыть «Интеграции → iiko».
4. Сохранить API Key.
5. Проверить доступ и получить список организаций iiko.
6. Выбрать организацию и терминальную группу.
7. Проверить валюту и формат адреса.
8. Выбрать внешнее меню и ценовую категорию (если она используется).
9. Сопоставить локальные блюда DAODES с iiko productId.
10. Обновить сопоставленные цены и свойства.
11. Выполнить первую синхронизацию стоп-листа.
12. Настроить вебхуки в iikoWeb и проверить получение событий.
13. Запустить предварительную проверку готовности передачи заказов.

## 4. Передача заказов

Автоматическая передача выключена по умолчанию.

Включение разрешается только после проверки:
- подключение активно;
- выбрано меню;
- валюта DAODES совпадает с валютой iiko;
- адресный формат iiko подтверждён для доставки;
- настроены часы работы и адреса DAODES;
- вебхуки включены;
- стоп-лист успешно синхронизирован;
- все активные блюда доставки/самовывоза сопоставлены;
- цена каждого блюда совпадает с последней ценой iiko;
- нет неподдерживаемых модификаторов, размеров и весовых позиций;
- для включённой онлайн-оплаты настроен payment mapping.

### Что сейчас отправляется

- самовывоз;
- доставка;
- простые блюда без неподдерживаемых модификаторов/размеров/веса;
- подтверждённая онлайн-оплата после webhook платёжного провайдера;
- cash/card on receipt без фиктивного платежа.

### Что блокируется

- несовпадение валют;
- несовпадение цен;
- недоступные по стоп-листу блюда;
- неизвестные iiko productId;
- модификаторы, размеры и вес, для которых ещё нет сопоставления;
- стоимость доставки или скидка, если они меняют итог DAODES относительно сопоставленных позиций;
- доставка при неподтверждённом формате адреса.

Заказ сначала сохраняется в DAODES. Передача выполняется фоновой задачей после commit транзакции. Идемпотентный ключ DAODES передаётся в iiko order.id.

## 5. Вебхуки

Публичный endpoint:

    POST /api/integrations/iiko/webhook

Поддерживаются:
- DeliveryOrderUpdate
- DeliveryOrderError
- StopListUpdate

В iikoWeb для DAODES необходимо выбрать эти типы событий. Вебхук быстро подтверждается HTTP 200, обработка идёт через очередь.

События дедуплицируются. Полный payload не сохраняется, чтобы не хранить лишние телефоны и адреса клиентов.

## 6. Доступные сервисы iiko

### Рабочий поток
- IikoAuthService
- IikoCloudClient
- IikoMenuService
- IikoStopListService
- IikoOrderService
- IikoWebhookService
- IikoOrderStatusSyncService
- IikoPaymentService
- IikoTableService

### Подготовленные read-only / вспомогательные модули
- IikoLoyaltyService: программы, поиск гостя по карте/телефону/id, расчёт скидки и история транзакций. Списание/начисление кошелька намеренно не открыто до согласования правил.
- IikoReservationService: создание, получение статуса, отмена и перенос бронирования. UI и модель бронирования DAODES ещё не подключены.
- IikoAnalyticsService: OLAP, экспорт доставок за период.
- IikoInventoryService: склады, остатки, накладные, списания, производство, перемещения, контрагенты и единицы измерения.
- IikoFinanceService: план счетов, счета, категории движения денег, балансовый отчёт, проводки и транзакции. Методы только для чтения.

## 7. Что ещё не включено

До получения доступа и согласования с рестораном не включать:
- dine-in table order;
- списание по гостевой карте/браслету и employee account;
- начисление/списание бонусов;
- возвраты и корректировки платежей;
- автоматическую перезапись локальных цен DAODES;
- автоматическую синхронизацию складских остатков в меню;
- финансовые операции записи.

Для dine-in нужно подтвердить, что идентификатор браслета/карты является cardNumber, cardTrack или другим идентификатором iiko, определить wallet/program и правила hold/chargeoff. Финансовые списания нельзя запускать без идемпотентности и согласования возвратов.

## 8. Тестирование

Локально/в CI:

    php artisan test --filter=Iiko
    php artisan migrate --pretend

На тестовой организации проверить:
1. авторизацию и список организаций;
2. меню и ценовую категорию;
3. сопоставление одного простого блюда;
4. стоп-лист;
5. тестовый самовывоз;
6. тестовую доставку;
7. DeliveryOrderUpdate и DeliveryOrderError;
8. StopListUpdate;
9. подтверждение оплаты и payment mapping;
10. повторную отправку одного заказа и отсутствие дубля.

Не проводить тесты на реальных гостях и реальных платежах без согласования с рестораном.

## 9. Ключевые ограничения безопасности

- Не логировать API Key, JWT, webhook authToken, номер карты, телефон и полный адрес.
- Не включать передачу заказов автоматически после сохранения API Key.
- При смене iiko организации/терминала выключать синхронизацию до повторной проверки.
- Не повторять заказ автоматически в другую iiko-организацию.
- При расхождении цены/валюты блокировать отправку.
- Не считать заказ оплаченным по одному факту создания в iiko.
- При недоступности iiko не удалять и не терять заказ DAODES.
